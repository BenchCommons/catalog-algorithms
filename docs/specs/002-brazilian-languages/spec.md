# 002 — Linguagens brasileiras e mantenedor no README

## O quê
Adicionar ao catálogo as linguagens criadas no Brasil ou feitas para programar em português, numa seção própria do README, e identificar @matbrgz como mantenedor na seção de contribuidores.

## Requisitos
1. Arquivos para VisuAlg, Portugol Studio, G-Portugol, Potigol, Égua/Delégua e BIRL, seguindo a convenção de nomes da spec 001.
2. Seção "Brazilian languages" no README, incluindo Lua e Elixir (já existentes) por referência.
3. Seção "Contributors" cita @matbrgz como mantenedor.

## Critérios de aceite
- Todo link do README aponta para um arquivo existente.

## Fora de escopo
- Executar os exemplos (nenhum toolchain dessas linguagens está disponível localmente).
